# The Aging Parent Care Kit

A static page for one kit at $24. Same kind of page as Everyday Essentials: a title, one line, three covers, the price, and one buy button.

## Checkout

Edit `checkout.config.js`. `agingParentCareKit` starts as an empty string. Paste a full `https://` link when checkout is ready. There is no card form on this page.

## Publish

Host this folder as static files. `.nojekyll` is included for GitHub Pages.

```bash
python3 -m http.server 8080
```
